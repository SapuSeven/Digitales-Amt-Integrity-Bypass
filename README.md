# Digitales-Amt-Integrity-Bypass

An XPosed/LSPosed module that allows the use of [Digitales Amt](https://play.google.com/store/apps/details?id=at.gv.oe.app) and [FinanzOnline [+]](https://play.google.com/store/apps/details?id=at.gv.bmf.bmf2go) on a rooted device.

<img src="https://img.shields.io/badge/FON%20[+]-v3.1.3-e63310?style=for-the-badge"/>
(Latest confirmed supported app versions, newer versions probably work as well. If not, please open an issue on GitHub.)

## Installation
Assuming you already have an Android device rooted using Magisk:

- Install the [Zygisk LSPosed](https://github.com/LSPosed/LSPosed/releases) Magisk module and reboot
- Install this [Integrity Check Bypass](https://github.com/SapuSeven/Digitales-Amt-Integrity-Bypass/releases) module
- Ensure "Digitales Amt"/"FON [+]" is **not** selected on the Magisk DenyList
- Enable the module in LSPosed for the apps you need and reboot
- Enjoy!

_If you have problems getting the LSPosed module to work on newer Android versions, you can try forks like https://github.com/mywalkb/LSPosed_mod or https://github.com/JingMatrix/LSPosed._
